### 4. 系統架構

本實驗的閉迴路控制流程如下：

`乒乓球位置 → HC-SR04 → Arduino 距離與速度估計 → PID 控制器 → SG90 Servo → 軌道傾斜 → 乒乓球位置`

HC-SR04 負責量測球的位置，Arduino 將測得距離和設定目標比較後計算誤差，並依 PID 輸出控制 Servo 角度。Servo 改變軌道傾角，讓球朝目標位置移動，再由感測器持續量測，形成回授控制系統。

本實驗以軌道中央為控制目標。由於 HC-SR04 量測的是探頭到球表面的距離，程式的目標值必須配合實際感測器安裝位置校正，不能直接將軌道的幾何中心距離視為量測值。

### 5. PID Control 原理

PID 控制器由三個部分組成：

- **P（比例控制）**：根據目前位置誤差提供修正量。`Kp` 越大，修正通常越明顯，但也可能造成振盪。
- **I（積分控制）**：累積長時間誤差，有助於消除穩態偏差；本次測試先設 `Ki = 0`，避免積分過度累積。
- **D（微分控制）**：根據球的位置變化速度提供抑制作用，降低衝過目標位置的可能性，但容易受到距離雜訊影響。

控制誤差與輸出可表示為：

```text
error = setPoint - filteredDistance
PIDoutput = Kp * error + Ki * integral - Kd * filteredVelocity
servoAngle = baselineAngle + PIDoutput
```

程式使用低通濾波處理距離及速度，並透過 `constrain()` 限制 Servo 角度。此外，對無效距離使用保護處理，並設計近端緊急修正及提前煞車條件。

### 6. 實驗注意事項

- HC-SR04 的探頭應對準乒乓球的行進路徑與球心高度，避免軌道邊緣、固定架造成近距離反射。
- 若 Serial Monitor 長時間只顯示約 3～5 cm，應確認讀到的是球而非固定物；此時只調高 PID 增益無法解決問題。
- `Sensor timeout` 或超出軌道範圍的距離應視為無效讀值，不宜直接進入 PID 控制。
- Servo 的基準角度應以軌道實際水平的位置校正，不能只用角度範圍的中點推定。
- Servo 的控制方向需要實測確認，確保球偏離中央時軌道傾斜方向能讓球回到目標。
- Servo 角度範圍要符合連桿機械行程，避免因傾斜過大而卡住或使球掉落。
- 過短的 HC-SR04 測量週期可能引起回波干擾；調快控制週期時應同時觀察讀值穩定性。
- 若 Serial Monitor 有 Servo 指令但馬達不轉，應檢查訊號腳位 D5、供電、共地與連桿機構。

### 7. 實驗心得

本次 Bonus Task 4-2 將超音波感測器、Servo Motor 和 PID 控制整合成 Ball-on-Beam 系統。與單純讓 Servo 轉動不同，這個實驗必須根據乒乓球的位置持續調整軌道傾角，因此感測器讀值是否正確，會直接影響整體控制效果。

實作過程中，我遇到超音波無法穩定偵測乒乓球、距離讀值受其他物體干擾，以及 Servo 修正角度不足等問題。透過觀察 Serial Monitor 的距離、速度、誤差與角度輸出，我逐步理解 PID 參數、濾波與機械結構如何互相影響。

這次實驗讓我了解，閉迴路控制不只是調整 `Kp`、`Ki`、`Kd`，還必須同時考慮感測器準確度、馬達供電、機構傳動與安全角度限制。後續若能改善量測穩定性並完成系統調參，就能進一步提高球在軌道中央的定位效果。
