### 3. 操作說明與成果

1. **RGB LED 電路連接**：使用共陰極（Common Cathode）RGB LED，將最長腳接至 Arduino 的 `GND`，紅、綠、藍三個色彩腳位分別串接一個限流電阻後連接至 Arduino 輸出腳位。

2. **藍色控制**：將可變電阻連接至 Arduino 的類比輸入腳位，利用 `analogRead()` 讀取可變電阻數值，並將讀取到的類比值轉換成 PWM 輸出，控制 RGB LED 的藍色亮度。

3. **紅色控制**：將按鍵連接至數位輸入腳位，使用 `digitalRead()` 讀取按鍵狀態。按下按鍵時開啟 RGB LED 的紅色通道，與原本的藍色疊加後呈現紫色。

4. **綠色控制**：使用 `Serial.begin(9600)` 初始化序列通訊，並在 Serial Monitor 輸入指定資料。當輸入 `1` 時，Arduino 開啟 RGB LED 的綠色通道。

5. **顏色疊加結果**：
   - 只調整可變電阻時：RGB LED 顯示 **藍色**。
   - 調整可變電阻並按下按鍵時：紅色與藍色疊加，RGB LED 顯示 **紫色**。
   - 再於 Serial Monitor 輸入 `1` 時：紅、綠、藍三色同時亮起，RGB LED 顯示 **白色**。

6. **實驗成果**：成功整合可變電阻、按鍵與 Serial Monitor 三種不同輸入方式，並依照不同輸入狀態控制 RGB LED 顏色，完成藍色、紫色與白色的逐步疊加效果。

### 4. 實驗原理

RGB LED 內部包含紅色、綠色與藍色三個 LED，可以透過分別控制三個色彩通道來產生不同顏色。本實驗使用共陰極 RGB LED，因此共同腳位接至 `GND`，各色腳位輸出 HIGH 或 PWM 訊號時即可點亮對應顏色。

本實驗將三種不同輸入分別對應到 RGB LED 的三個色彩通道：

- **R（Red）**：由按鍵的數位輸入控制。
- **G（Green）**：由 Serial Monitor 的序列輸入控制。
- **B（Blue）**：由可變電阻的類比輸入控制。

當多個色彩通道同時亮起時，會產生加法混色效果，例如紅色加藍色會形成紫色，而紅、綠、藍三色同時亮起時會接近白色。
