### 3. 操作說明與成果

1. **電路連接**：將可變電阻兩側接腳分別連接 Arduino 的 `5V` 與 `GND`，中間接腳連接至類比輸入腳位；LED 則透過限流電阻連接至支援 PWM 輸出的數位腳位。

2. **讀取類比訊號**：在程式中使用 `analogRead()` 讀取可變電阻的輸入值。Arduino Uno 的類比數位轉換器（ADC）為 10-bit，因此讀取結果範圍為 **0～1023**。

3. **控制 LED 亮度**：將 `analogRead()` 所得到的 0～1023 數值轉換成 `analogWrite()` 可使用的 **0～255 PWM 輸出值**，再輸出至 LED。當旋轉可變電阻使類比值增加時，LED 亮度會逐漸提高；當類比值減少時，LED 亮度則逐漸降低。

4. **序列埠監控**：使用 `Serial.begin(9600)` 初始化序列通訊，並透過 `Serial.println()` 每隔 **1 秒**將目前的類比輸入值輸出至 Arduino IDE 的 Serial Monitor。

5. **實驗成果**：旋轉可變電阻時，可以觀察到 Serial Monitor 中的數值隨旋鈕位置改變，數值約介於 **0～1023**。同時 LED 的亮度也會隨輸入值同步改變，輸入值越大時 LED 越亮，成功完成利用類比輸入控制 PWM 輸出的功能。

### 4. 實驗原理與問題說明

`analogRead()` 的最大回傳值為 **1023**，因為 Arduino Uno 使用 **10-bit ADC**，10-bit 可以表示的數值共有：

2^10 = 1024

因此數值範圍為 **0～1023**。

另一方面，`analogWrite()` 的 PWM 控制值範圍為 **0～255**，因此需要將 `analogRead()` 的 0～1023 輸入範圍轉換成 0～255，例如可使用 `map()` 進行數值映射。如此即可讓可變電阻由最小值轉至最大值時，LED 亮度也由最暗逐漸變成最亮。
